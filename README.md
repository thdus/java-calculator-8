# java-calculator-precourse

## 구현할 기능 목록

### 1. 입력 받기	
사용자로부터 문자열 입력을 받는다.

### 2. 빈 문자열 처리	
입력값이 ""일 경우 결과는 0을 반환한다.

### 3. 기본 구분자 처리	
쉼표(,), 콜론(:)을 기준으로 문자열을 분리한다.

### 4. 커스텀 구분자
"//"와 "\n" 사이의 문자를 커스텀 구분자로 인식한다.

### 5. 숫자 변환 및 합산	
분리된 문자열을 정수로 변환한 뒤 합산한다.

### 6. 예외 처리	
음수 또는 숫자가 아닌 값이 존재할 경우 IllegalArgumentException을 발생시킨다.

### 7. 결과 출력	
계산된 결과를 "결과 : {sum}" 형태로 출력한다.
